## 🚀 Usage
To use the program created for this model
```py
>>> from ui.MainWindow import mainWindow
>>> 
>>> window = mainWindow()
>>> window.run()
```
or you can run it from the `program.py` file

To use the model itself
```py
>>> from services.Model import model
>>> 
>>> model = model()
```
